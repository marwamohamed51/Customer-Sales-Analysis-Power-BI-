# Customer Sales Analysis Dashboard

## Overview
This project presents a **Customer Sales Analysis Dashboard** built using **Power BI** to analyze sales performance, customer behavior, and product performance.  
The dashboard provides interactive insights into sales trends, forecasts, customer distribution, and product performance across different regions.

The dashboard design was first created in **Figma** and then implemented in **Power BI** to combine **data visualization** with a clean and modern UI design.

## Key Features

### Sales Performance
- Total Sales KPI
- Sales Forecast vs Actual Sales
- Sales Variance and Variance %

### Customer & Product Insights
- Total Customers
- Total Products
- Number of Brands
- Number of Categories
- Number of States

### Sales Analysis
- Total Sales by Category
- Total Sales by Continent
- Total Sales by Country Region
- Sales by Education Level

### Product Performance
- Top 10 Products by Sales
- Contribution of Top Products to Total Sales

### Forecast Analysis
- Comparison between **Forecast Sales 2009** and **Actual Sales 2009**

### Drill-down Analysis
A hierarchical visual showing:
- Country
- State
- Brand

This helps explore sales distribution across different levels.

---

## Filters (Slicers)
Users can interact with the dashboard using:
- Year
- Country Region
- State
- Brand

These filters allow dynamic analysis of the data.

---

## Key Insights
- North America contributes the largest portion of total sales.
- Home Appliances is the top-performing product category.
- Sales in 2009 were significantly lower than the forecast.
- California shows the highest sales among U.S. states.
